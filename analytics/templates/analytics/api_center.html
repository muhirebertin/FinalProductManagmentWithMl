Examples

1. Send a new incoming order (it is scored and appears live on the dashboard)

curl -X POST {{ base_url }}/api/v1/orders/ \
  -H "X-API-Key: YOUR_KEY" -H "Content-Type: application/json" \
  -d '{"product_code": "Bag-002", "quantity": 8, "due_date": "2026-12-15",
       "customer": "Kigali Heights Boutique", "channel": "Corporate"}'

2. Ask for a prediction without storing anything

curl -X POST {{ base_url }}/api/v1/predict/ \
  -H "X-API-Key: YOUR_KEY" -H "Content-Type: application/json" \
  -d '{"product_code": "Shoe-003", "quantity": 12, "due_date": "2026-12-20", "artisan_id": 3}'

3. Python client

import requests
API = "{{ base_url }}/api/v1"
headers = {"X-API-Key": "YOUR_KEY"}
records = requests.get(f"{API}/records/", params={"page_size": 1000}, headers=headers).json()
print(records["meta"]["total"], "training records")

4. Stream simulated orders from the command line

python manage.py simulate_orders --count 20 --interval 3 --api-url {{ base_url }} --api-key YOUR_KEY
